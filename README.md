# Comwell Digital Elevplan

Dette projekt er udviklet som en digital løsning til Comwells kokkeuddannelse. Formålet med systemet er at digitalisere elevplaner og skabe et bedre overblik over elevernes praktikforløb, læringsmål og progression gennem uddannelsen.

Løsningen gør det muligt at oprette elevplaner ud fra forskellige templates for praktikperioder, arbejde med mål og delmål, følge deadlines og registrere status på opgaver. Systemet understøtter flere roller, herunder elev, køkkenchef og HR, så brugerne får adgang til de planer og oplysninger, der er relevante for dem.

Projektet blev udviklet som en del af et studieprojekt i tæt samarbejde med Comwell, hvor krav og funktionalitet løbende blev afstemt gennem dialog med virksomheden. Målet var at skabe en realistisk og brugervenlig digital løsning, som kunne understøtte arbejdsgange omkring kokkeelever i praksis.

Projektet er bygget med C#, .NET, Blazor, ASP.NET Core, MongoDB og er struktureret med adskillelse mellem modeller, backend og frontend.
